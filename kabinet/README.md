# Кабинет – дигитална таблица за зрение

Адрес: https://ioptics-bg.com/kabinet/ (не се индексира от търсачките).

## Настройка на Firebase (еднократно, ~10 минути)

1. Отворете https://console.firebase.google.com → **Add project** (например `ioptics-kabinet`). Google Analytics не е нужен.
2. **Build → Authentication → Get started → Sign-in method → Email/Password → Enable.**
3. **Authentication → Settings → Authorized domains** → добавете `ioptics-bg.com`.
4. **Authentication → Templates** → по желание сменете езика на писмата на български.
5. **Build → Firestore Database → Create database** (регион `europe-west`, production mode).
   В раздел **Rules** поставете съдържанието на `firestore.rules` от тази папка и натиснете **Publish**.
6. **Project settings (зъбното колело) → Your apps → Web (`</>`)** → регистрирайте приложение.
   Копирайте `apiKey`, `authDomain`, `projectId`, `appId` във файла `kabinet/firebase-config.js`.

Регистрираните потребители се виждат в Authentication → Users (там може и да се изтриват или блокират).
В Firestore → `users` са имената, практиките и запазените настройки.

## Какво се пази и къде
- **На устройството** (за конкретния екран и стая): калибриране, разстояние до пациента, огледален режим.
  Така два телевизора с един акаунт не си разменят размерите. Нов екран се калибрира веднъж.
- **В акаунта** (еднакви навсякъде): означение (V / 6/6 / 20/20 / logMAR), фон на оптотипите, показване на стойностите.

## Калибриране
1. ▲ ▼ нагласят размера на екрана в инчове (напр. 43″).
2. Допрете банкова карта до рамката и с ◀ ▶ я донагласете с по един пиксел.
3. OK запазва. На телевизор изключете overscan („Just Scan“, „Screen Fit“).

Калибрирането се пази като размер на един физически пиксел, затова не зависи от мащаба (zoom) на браузъра.

## Управление
| Бутон | Действие |
|---|---|
| ▲ ▼ | по-голямо / по-малко (стъпка 0,1 logMAR) |
| ◀ ▶ | режим (таблица / ред / знак / ред червено-зелен / знак червено-зелен, вид цел и т.н.) |
| 5 или червен бутон (в тест за острота) | червено-зелен фон под същите знаци и обратно |
| OK | нови знаци |
| Назад | меню |
| 1–9 | директно към тест |
| червен / зелен / жълт / син (от менюто) | дуохром / букви / астигматизъм / крос цилиндър |
| Info или 0 | скрива/показва стойностите |
| M (на клавиатура) | огледален режим |

## Астигматизъм
- **Часовник:** по-малкото число при най-ясната линия × 30 = ос на минус цилиндъра.
- **Ветрило:** числото при най-ясната линия е оста на минус цилиндъра (TABO).

## Бележки
- Защитата е „мека“: без вход приложението не се показва, но файловете са публични в GitHub.
- В менюто на телевизора изключете overscan („Just Scan“, „Screen Fit“).
- Обърнатото E и пръстенът на Ландолт са точни по стандарт (решетка 5×5). Буквите Sloan са рисувани по същата решетка
  и са близки до оригиналните, но не са сертифициран шрифт; цифрите използват шрифт Arial Bold.
- Тестовете с бутоните се пускат автоматично преди всяка версия (всички стрелки, OK, Назад, калибриране).
